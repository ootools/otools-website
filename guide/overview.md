# 文档概览

OTools 是一款面向专业场景的桌面版小程序平台，通过海洋生态插件体系与 Tabs 多任务化，让工具成为可组合、可复用的工作流模块。

## 文档结构

- **更新日志**：基于最近 100 条 Git 提交记录整理的阶段性演进摘要，便于快速了解近期新增能力与修复重点。
- **OTools API**：运行时能力、系统接口、Native 插件调用、本地/同步状态存储。
- **开发者模式**：插件创建、绑定、调试、构建与发布流程。
- **兼容**：已有 Tauri 工程同时兼容独立发布与 OTools 插件发布。
