主な機能

可視化された差分

インライン / 並列の 2 種類。変更ブロック単位・行単位でのリセットに対応。

AI コミットメッセージ

ステージ済みの変更から規約に沿ったメッセージを自動生成。テンプレートも調整可能。

内蔵ターミナル

2 つの使い方

この機能だけの軽快なアプリか、既存の OTools に組み込むか。

おすすめ

単体版

同じエンジンで、このプラグインの機能だけを備えた専用デスクトップアプリ。ダブルクリックですぐ使え、OTools は不要です。

  • macOS · .dmg
  • Windows · .exe
  • Linux · .AppImage / .deb / .rpm
単体版をダウンロード

インストーラーは GitHub Releases にあります。自動更新内蔵。

プラグイン版

既存の OTools に追加し、他のツールと同じワークスペースでタブとショートカットを共有。

  1. OTools デスクトップ版をダウンロードしてインストール
  2. 「プラグインマーケット」を開く
  3. このプラグインを検索してワンクリックでインストール
プラグイン版を入手

プラグイン版は OTools と一緒に更新されます。
