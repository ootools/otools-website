# 主な機能

OTools は「ツール統合・プラグインエコシステム・Tabs マルチタスク」を高性能デスクトッププラットフォームとして統合します。以下はコア機能の概要です。

## 1. Tabs マルチタスク

- 複数のツールを同時に開き、コンテキストを保持。
- プラグイン間の切り替えが高速で再読み込み不要。
- 生産性ワークフローに適合し、ウィンドウ切替コストを削減。

## 2. 海洋エコシステムのプラグイン体系

- 内蔵ツール + コミュニティプラグインで完全なエコシステム。
- ホット更新、バージョン履歴、マーケット配布に対応。
- 統一されたプラグインディレクトリと管理入口。

## 3. 高性能デスクトップランタイム

- ローカル能力呼び出しで高速・安定。
- Native 動的ライブラリで性能上限を拡張。
- 統一 API ブリッジで呼び出しが一貫。

## 4. 開発者フレンドリー

- 開発者センターで作成・バインド・デバッグまで一括。
- Web/Vue と Rust ネイティブのワンクリック初期化。
- パッケージングと公開まで一連の流れ。

## 5. 内蔵モジュール一覧

- Git プロジェクト管理と AI 補助ドキュメント
- HTTP / MQTT / FTP ネットワークツール
- Docker と SSH/SFTP ターミナル
- データベース管理（DBM）
- パケットキャプチャ＆リプレイ（Pakcap）
- スクリーンショット、音声、ディスクなど
