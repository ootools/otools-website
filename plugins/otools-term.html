两种用法，任选其一

想要一个只做这件事的干净应用，还是并入已有的 OTools 工作台？

推荐

独立版

与宿主同源、但只带本插件功能的独立桌面应用，双击即用，无需先装 OTools。

  • macOS · .dmg
  • Windows · .exe
  • Linux · .AppImage / .deb / .rpm
下载独立版

安装包在 GitHub Releases；应用内置自动更新。

插件版

并入已有的 OTools，与其它工具在同一工作台里协作，共享标签页与快捷键。

  1. 下载并安装 OTools 桌面版
  2. 打开「插件市场」
  3. 搜索本插件并一键安装
获取插件版

插件版会随 OTools 一起更新。
