주요 기능 ​

OTools는 “도구 통합, 플러그인 생태계, Tabs 멀티태스킹”을 하나의 고성능 데스크톱 플랫폼으로 통합합니다. 아래는 핵심 기능 개요입니다.

1. Tabs 멀티태스킹 ​

  • 여러 도구를 동시에 열어 컨텍스트를 유지합니다.
  • 플러그인 간 빠른 전환으로 재로딩이 필요 없습니다.
  • 생산성 워크플로에 최적화되어 창 전환 비용을 줄입니다.

2. 해양 생태계 플러그인 시스템 ​

  • 내장 도구 + 커뮤니티 플러그인이 완전한 생태계를 구성합니다.
  • 핫 업데이트, 버전 기록, 마켓 배포 지원.
  • 통합 플러그인 디렉터리와 관리 진입점을 제공합니다.

3. 고성능 데스크톱 런타임 ​

  • 로컬 기능 호출로 빠르고 안정적입니다.
  • Native 동적 라이브러리로 성능 상한을 확장합니다.
  • 통합 API 브리지를 통해 호출 방식이 일관됩니다.

4. 개발자 친화적 ​

  • 개발자 센터에서 생성, 바인딩, 디버깅까지 한 번에.
  • Web/Vue 스캐폴딩과 Rust 네이티브 프로젝트를 원클릭으로 생성.
  • 마켓 배포를 위한 패키징 프로세스 제공.

5. 내장 모듈 ​

  • Git 프로젝트 관리 및 AI 보조 문서
  • HTTP / MQTT / FTP 네트워크 도구
  • Docker 및 SSH/SFTP 터미널
  • 데이터베이스 관리(DBM)
  • 패킷 캡처 및 재생(Pakcap)
  • 스크린샷, 오디오, 디스크 유틸리티 등
