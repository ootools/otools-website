Git

화면 갤러리

실제 플러그인 UI로 렌더링한 스크린샷(라이트/다크는 사이트 테마를 따릅니다).

실제 화면

각 기능에 실제 스크린샷을 함께 제공해 일상적인 모습을 확인하세요.

Git
01

다중 저장소 워크벤치

열 개 넘는 저장소를 한 번에: 커밋 수, 앞섬/뒤짐, 미커밋 변경을 한눈에. 펼치면 서브모듈도 보입니다.

Git
02

파일 탐색

트리에서 저장소 파일을 열어 보고 편집한 뒤, 변경 목록으로 돌아와 바로 스테이징할 수 있습니다.

Git
03

내장 터미널

같은 창에서 git 명령을 실행하고 저장소 컨텍스트에 맞춰 디렉터리를 전환할 수 있어 별도 터미널이 필요 없습니다.

핵심 기능

기능 목록이 아니라, 매일 쓰기 위해 다듬은 디테일.

다중 저장소 워크벤치

열 개 넘는 저장소를 한 번에: 커밋 수, 앞섬/뒤짐, 미커밋 변경을 한눈에. 펼치면 서브모듈도 보입니다.

파일 탐색

트리에서 저장소 파일을 열어 보고 편집한 뒤, 변경 목록으로 돌아와 바로 스테이징할 수 있습니다.

시각적 차이

인라인/나란히 보기 두 가지, 변경 블록·줄 단위 리셋을 지원합니다.

AI 커밋 메시지

스테이징된 변경으로 규칙에 맞는 메시지를 자동 생성합니다. 템플릿 조정도 가능합니다.
