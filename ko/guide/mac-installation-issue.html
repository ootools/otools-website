macOS 설치 문제

On this page

macOS 설치 일반적인 문제 - "앱 손상됨" 해결 방법 ​

macOS에 OTools 또는 기타 서드파티 애플리케이션을 설치할 때, "xxx.app이(가) 손상되어 열 수 없습니다. 휴지통으로 이동해야 합니다"와 같은 메시지를 볼 수 있습니다. 이는 일반적으로 macOS 보안 설정 때문입니다.

왜 이런 문제가 발생하나요? ​

macOS는 Windows보다 프로그램에 대한 통제가 매우 엄격하며, 앱스토어가 아닌 곳에서 다운로드한 앱 설치 시 자주 "xxx.app이(가) 손상됨"이라는 메시지가 나타납니다. macOS 10.15 이후에는 서명되지 않은 앱에 대한 권한이 더욱 제한되어 이러한 문제가 더 자주 발생하게 되었습니다.

해결 방법 ​

방법 1: "모든 소스에서 다운로드한 앱" 허용 설정 ​

  1. "시스템 환경설정 -> 보안 및 개인정보 보호 -> 일반" 탭을 엽니다
  2. "다음 위치에서 다운로드한 앱 허용" 옵션에 "모든 소스"가 활성화되어 있는지 확인합니다
  3. 활성화되어 있지 않다면 왼쪽 하단의 작은 노란 자물쇠 아이콘을 클릭하여 잠금을 해제한 다음 "모든 소스"를 선택합니다

설정에 "모든 소스" 옵션이 보이지 않는 경우, 터미널을 열고 다음 명령어를 입력합니다:

bash
sudo spctl --master-disable

컴퓨터의 로그인 비밀번호를 입력하고 Enter 키를 누르면, 설정에서 "모든 소스" 옵션을 확인할 수 있습니다.

보통 이 설정 후에는 앱이 정상적으로 설치됩니다. 하지만 macOS 버전이 최신일 경우, 아래의 단계처럼 애플의 게이트키퍼 우회가 여전히 필요할 수 있습니다.

방법 2: 애플의 게이트키퍼 인증 우회 ​

방법 1로도 문제가 해결되지 않을 경우, 다음 단계를 시도해 보세요:

  1. 터미널 열기
  2. 다음 명령어를 입력하지만, 아직 Enter 키를 누르지는 마세요:
bash
sudo xattr -rd com.apple.quarantine
  1. Finder(파인더)의 응용프로그램 폴더에서 OTools.app 찾기
  2. OTools.app을 터미널 창에 드래그하면 명령어 뒤에 앱 경로가 자동으로 추가됩니다
  3. Enter 키를 누르고 비밀번호를 입력하면 앱을 직접 실행할 수 있습니다

방법 3: 오른쪽 클릭으로 열기(처음 설치할 때 적합) ​

처음 설치할 경우에는 다음과 같이 할 수도 있습니다:

  1. Finder에서 OTools.app 찾기
  2. 오른쪽 클릭(또는 Control 키를 누른 상태에서 클릭)
  3. "열기" 선택
  4. 보안 경고 팝업에서 "열기" 클릭

중요 참고 사항 ​

  • OTools은 Tauri 프레임워크를 사용하여 구축된 정당한 데스크톱 애플리케이션입니다
  • 컴퓨터가 악성 소프트웨어의 영향을 받지 않습니다
  • 이 문제는 애플리케이션 자체가 아니라 애플의 보안 정책으로 인해 발생하는 것입니다
