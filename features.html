功能亮点 ​

OTools 将“工具集成、插件生态、Tabs 多任务”合并为一个高性能桌面平台。以下是核心能力概览。

1. Tabs 多任务化 ​

  • 多个工具并行打开，保持上下文。
  • 不同插件之间快速切换，无需重复加载。
  • 适配生产力工作流，减少窗口切换成本。

2. 海洋生态插件体系 ​

  • 内置工具 + 社区插件形成完整生态。
  • 插件可热更新，支持版本记录与市场分发。
  • 统一插件目录与管理入口。

3. 高性能桌面运行时 ​

  • 本地能力调用，速度快、稳定性高。
  • 支持 Native 动态库扩展，提升性能上限。
  • 统一 API 桥接，插件调用简单一致。

4. 开发者友好 ​

  • 内置开发者中心，创建、绑定、调试插件一步到位。
  • 一键初始化 Web/Vue 工程与 Rust 原生工程。
  • 打包发布流程完整，可直接进入市场分发。

5. 内置模块一览 ​

  • Git 项目管理
  • HTTP / MQTT / FTP 网络工具
  • Docker 与 SSH/SFTP 终端
  • 数据库管理（DBM）
  • 抓包与回放（Pakcap）
  • 截图、音频、磁盘等通用工具
能力分组包含内容
系统能力剪贴板、文件与路径、通知、Shell 打开与管理
运行时信息平台、版本、插件 UUID、运行环境变量
Native 能力原生插件加载、调用、探测、热更新
插件状态本地状态与同步状态、支持 scheme 多文件存储
