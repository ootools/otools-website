# Feature Highlights

OTools combines tool integration, plugin ecosystem, and Tabs multitasking into a high-performance desktop platform. Here is an overview of the core capabilities.

## 1. Tabs Multitasking

- Open multiple tools in parallel and keep context.
- Switch quickly across plugins without repeated loading.
- Fits productivity workflows and reduces window switching.

## 2. Ocean-Ecosystem Plugins

- Built-in tools + community plugins form a complete ecosystem.
- Hot updates, version history, and marketplace distribution.
- Unified plugin directory and management entry.

## 3. High-Performance Desktop Runtime

- Local capability calls, fast and stable.
- Native dynamic libraries extend the performance ceiling.
- Unified API bridge for consistent plugin calls.

## 4. Developer Friendly

- Built-in developer center: create, bind, debug plugins.
- One-click Web/Vue scaffolding and Rust native project.
- Complete packaging workflow for marketplace distribution.

## 5. Built-in Modules

- Git project management with AI-assisted docs
- HTTP / MQTT / FTP networking tools
- Docker and SSH/SFTP terminal
- Database management (DBM)
- Packet capture and replay (Pakcap)
- Screenshots, audio, disk utilities and more
