Documentation Overview ​

OTools is a desktop mini-app platform for professional scenarios. With the ocean-ecosystem plugin system and Tabs multitasking, tools become composable and reusable workflow modules.

Documentation Structure ​

  • OTools API: runtime capabilities, system interfaces, Native plugin calls, local/sync state storage.
  • Developer Mode: plugin creation, binding, debugging, build and release workflow.
  • Compatibility: make an existing Tauri project work for both standalone distribution and OTools plugin distribution.
