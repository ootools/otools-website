Zwei Nutzungsarten

Eine fokussierte App nur dafür – oder als Plugin in deinem bestehenden OTools?

Empfohlen

Standalone-Version

Eine eigene Desktop-App mit derselben Engine, aber nur den Funktionen dieses Plugins. Doppelklick und los – OTools nicht nötig.

  • macOS · .dmg
  • Windows · .exe
  • Linux · .AppImage / .deb / .rpm
Standalone herunterladen

Installer liegen auf GitHub Releases; integrierte Auto-Updates.

Plugin-Version

Zu deinem bestehenden OTools hinzufügen und mit anderen Tools im selben Workspace arbeiten – Tabs und Shortcuts geteilt.

  1. OTools Desktop herunterladen und installieren
  2. Den „Plugin-Marktplatz“ öffnen
  3. Dieses Plugin suchen und mit einem Klick installieren
Plugin-Version holen

Die Plugin-Version wird zusammen mit OTools aktualisiert.
