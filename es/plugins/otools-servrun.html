Dos formas de usarlo

¿Una app enfocada solo en esto, o un plugin dentro de tu OTools actual?

Recomendado

Versión independiente

Una app de escritorio dedicada, mismo motor pero solo con las funciones de este plugin. Doble clic y listo: no requiere OTools.

  • macOS · .dmg
  • Windows · .exe
  • Linux · .AppImage / .deb / .rpm
Descargar versión independiente

Los instaladores están en GitHub Releases; actualización automática integrada.

Versión plugin

Añádelo a tu OTools y trabaja junto a tus otras herramientas, compartiendo pestañas y atajos.

  1. Descargar e instalar OTools de escritorio
  2. Abrir el «Mercado de plugins»
  3. Buscar este plugin e instalarlo con un clic
