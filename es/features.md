# Características destacadas

OTools integra herramientas, ecosistema de plugins y multitarea con Tabs en una plataforma de escritorio de alto rendimiento. Aquí tienes un resumen de las capacidades clave.

## 1. Multitarea con Tabs

- Abre varias herramientas en paralelo y conserva el contexto.
- Cambia rápido entre plugins sin recargar.
- Ideal para flujos de productividad y menos cambios de ventana.

## 2. Ecosistema de plugins “océano”

- Herramientas integradas + plugins de la comunidad forman un ecosistema completo.
- Actualizaciones en caliente, historial de versiones y distribución en marketplace.
- Directorio unificado de plugins y acceso centralizado.

## 3. Runtime de escritorio de alto rendimiento

- Llamadas locales rápidas y estables.
- Bibliotecas dinámicas Native para ampliar el rendimiento.
- Puente API unificado para llamadas consistentes.

## 4. Enfocado en desarrolladores

- Centro de desarrolladores integrado: crear, vincular y depurar.
- Inicialización con un clic de proyectos Web/Vue y Rust nativo.
- Flujo completo de empaquetado para distribución.

## 5. Módulos integrados

- Gestión de proyectos Git y documentación asistida por IA
- Herramientas de red HTTP / MQTT / FTP
- Terminal Docker y SSH/SFTP
- Gestión de bases de datos (DBM)
- Captura y reproducción de paquetes (Pakcap)
- Capturas, audio, disco y utilidades generales
